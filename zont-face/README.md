# Stereoo ZONT Face — TicWatch Pro 3 GPS, Wear OS 2.45

Нативный циферблат для Wear OS 2 с реальным соединением с ZONT ZTC-710. Минимальная версия Android API 26. Не работает как циферблат на Wear OS 4+ (требуется WFF).

## Функции
- Цифровое время, дата, настоящие аналоговые часовая/минутная/секундная стрелки;
- Фото тёмно-зелёной Suzuki Grand Vitara XL7 2005 из фотографии владельца; номер `Х125ХР 22 RUS`;
- Состояние охраны и двигателя, температура салона и двигателя, уровень батареи часов;
- Напряжение/топливо показываются только если ZONT действительно их возвращает, без вымышленных данных;
- Кнопки охраны, снятия, автозапуска/остановки двигателя с подтверждением;
- Тёмный Ambient (Always-On) режим и редкие опросы сервера.

## Установка
1. Скачайте APK из GitHub Actions артефакта `Stereoo-ZONT-Face-WearOS2-APK`, установите **на часы**, не на телефон.
2. Откройте `Stereoo ZONT Face` в меню приложений часов и укажите логин/пароль от **my.zont.online**. Никакие учётные данные не включены в APK.
3. Нажмите «Проверить ZONT». Выберите своё устройство, если ZONT найдёт больше одного.
4. Зажмите текущий циферблат, выберите `Stereoo ZONT Face`.
5. Нажатие на «ZONT» открывает настройки, три нижние кнопки вызывают подтверждение команд.

Важно: при управлении охраной и автозапуском API может отвечать `ok:true`, даже когда команда не дошла до прибора. Программа повторно запрашивает состояние, сообщает «не подтверждено», если оно не изменилось. Не запускать двигатель в закрытом гараже.

### API
Официальные методы: `POST https://my.zont.online/api/devices` (`load_io:true`) и `POST https://my.zont.online/api/set_io_port` (порт `guard-state` / `auto-ignition`). HTTP Basic Auth только через TLS; пароль хранится в Android KeyStore (AES-GCM). При отсутствии связи показывается статус ошибки; старые данные не выдаются за новые. 

Настоящее физическое напряжение АКБ и уровень топлива зависят от доступных параметров ZONT и датчиков. В демонстрационном макете использовались примерные значения, но здесь они не подставляются вместо реальных.
